# ToriiHalo Score Emojis

Original geometric lettering drawn by render.ps1. No Bathbot or osu! artwork,
font files or traced shapes are used. PNG output is transparent, 128 x 128.
Run the PowerShell script to regenerate all ten files.

Upload PNGs in Discord Server Settings > Emoji, keeping filenames as names.
Start a new /rs after upload. No restart or emoji IDs need to be configured.
ToriiHalo uses text if an emoji is missing or unavailable to the bot.

X/XH mean SS/silver SS. SH means silver S.
